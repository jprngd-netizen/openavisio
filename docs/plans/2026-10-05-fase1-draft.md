## Decisions (with rationale)
1. Phase 1 ships the full domain with fakes; no live external calls (plan's F1, hardened).
2. Numbering happens at *issue* time, not draft time — 30s token + pool semantics (manual §2.2.4.4, §2.3.1).
3. Number pools are persisted as `PrescriptionNumberAllocation`; one number is burned per prescription via `PrescriptionNumber` (unique).
4. Prescription is a distinct model, not a `DocumentReference`; the signed PDF is archived *into* a `DocumentReference` with `processing_status="complete"` so OCR never runs.
5. Prescriber identity is snapshotted (JSONB) so the legal record survives User erasure.
6. `PrescriptionType` includes `simple` for unnumbered ordinary prescriptions; SNCR types are a subset.
7. Ports (`Protocol`) + fakes (`FakeSncrNumbering`, `FakeSigner`) keep tests offline.
8. Idempotency keys on allocate/sign/archive.

## Scope IN
Phase 1 domain: models+migration, state machine, ports+fakes, numbering service, archival service, schemas+router+autosave, erasure/retention, frontend editor, i18n, offline tests.
